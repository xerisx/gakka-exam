# 学科試験ドリル

運転免許（本免許）の学科模擬試験で間違えた問題を、スマホから○×形式で復習するための静的サイト。

**サイト**: https://xerisx.github.io/gakka-exam/

## 仕組み

```
mistakes.md   ← 誤答ノート（唯一の入力。手で書く／Claude Code が追記する）
images/       ← 標識などの画像
web/          ← サイト本体のソース（HTML / CSS / JS）
scripts/build.mjs  ← mistakes.md をパースして docs/ を生成
docs/         ← 生成物。GitHub Pages はこのフォルダを配信する（コミット対象）
```

**問題を増やすときは `mistakes.md` に追記してコミットするだけ。**
`.githooks/pre-commit` がコミットのたびに `docs/` を作り直して stage する
（クローン直後は `git config core.hooksPath .githooks` を一度実行する）。

## mistakes.md の書式

```markdown
## 2026-09-13 模擬試験（第1回）

### 001 駐停車の余地
- **問題**: 歩道や路側帯のない道路に駐車や停車をするときは……
- **正解**: ×
- **ポイント**: 歩道・路側帯がないときは、左側に余地をあける必要はない。

### 018 【標識】原付の二段階右折 (Q33)
- **画像**: images/q033-gentsuki-nidankai-usetsu.png （青丸・矢印＋「原付」）
- **問題**: この標識のある交差点で右折しようとする原動機付自転車は……
- **正解**: ×
- **ポイント**: 二段階右折でも、直進している間 **も右折の合図を行う**。
```

- `## <日付> <タイトル>` が模擬試験1回分の区切り。
- `### <番号> <タイトル>` が1問。`【標識】` や `(Q33)` は表示時に除去される。
- `- **問題**:` と `- **正解**:`（`○` または `×`）は必須。それ以外の問題はスキップされ、ビルド時に警告が出る。
- `- **画像**:` は任意。カッコ内の注記は画像のキャプションになる。
  スクリーンショットには答えと解説が写り込んでいるので、ビルド時に
  標識・標示の図だけを自動で切り出す（`scripts/lib/crop.mjs`）。
  `images/` の原本はそのまま、配信されるのは切り抜き後の `docs/images/` だけ。
  図が写っていないスクリーンショットは画像なしの問題として扱われる。
- `- **ポイント**:` が解説として表示される。`**強調**` はそのまま太字になる。

## ローカルで確認

```sh
node scripts/build.mjs
cd docs && python3 -m http.server 8000   # → http://localhost:8000
```

## 機能

- ○×の2択、回答するとその場で正解と解説を表示
- 出題範囲: すべて / 苦手 / 未挑戦 / 標識つき、模擬試験の回ごとの絞り込み
- 「苦手」は **2回連続で正解するまで残る**。間違えると連続数は0に戻る（まぐれ当たりで卒業させないため）
- 出題は毎回シャッフル。解答履歴は端末の localStorage に保存（サーバーには何も送らない）
- 結果画面から間違えた問題だけを再挑戦できる

---

正解・解説は自習用のメモなので、最終確認は教本で。
